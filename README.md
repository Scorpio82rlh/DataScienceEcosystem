# RT CSE Arcade Preview

This project is a static prototype. You can open the preview in any of these ways:

1. **Local development server**
   ```bash
   npm start
   ```
   Then open http://localhost:3000/ in your browser.

2. **Direct file preview**
   Open `index.html` in your browser (e.g., drag the file into a new tab).

The landing page hero includes a “Start a free case” button that scrolls to the interactive simulation. Use the **Reset case** button to run the branching workflow again.
